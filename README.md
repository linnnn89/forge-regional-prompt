# Forge Regional Prompt

Forge 区域提示词插件，可为画面不同位置设置独立提示词。界面中仍显示为 **Forge Couple**。

## 当前状态

**2026-09-27 保守使用基线，暂停进一步效果实验。** 本次冻结保留已有功能，不更换采样后端、不升级依赖。界面中的 v7.1.0 是继承的版本标识；本项目的具体状态以 Git 提交和本文说明为准。

Basic 等分区域已在本地使用中起效。Advanced 和 Mask 提供了矩形分区、构图模板与手绘蒙版，但**蒙版比例正确，不等于生成人物会按这个比例占位**。

目前还没有解决的目标是：左右占位不等，同时让人物自然互动，并保持完整的背景、光照和透视。项目保留了几种实验后端，默认关闭；它们是探索记录，不是已完成的构图控制方案。

### 日常使用设置

- 在 Settings → Forge Couple 中关闭「联合注意力」「区域去噪融合」「局部画布预测」，点击 Apply settings。关闭联合注意力和区域去噪融合后，使用原注意力路径。
- Basic、Advanced、Mask 继续使用现有区域界面。Basic 等分是目前本地使用证据最充分的路径；Advanced / Mask 的可用界面和正确蒙版不代表精确构图已经验证。
- 不把实验中的区域权重 0.1、三等分人体描述等设为默认预设。它们只在单个 seed 上探索过。
- 如不确定旧运行状态，停止当前生成后重启 Forge 并刷新页面，再应用上述设置。升级代码不会自动覆盖已有个人设置。
- 这里的“基线”表示保守冻结，不是经过全面兼容性测试的稳定发布。更多已知限制和完整探索见 [实验记录](docs/EXPERIMENTS.md)。

## 原理

插件在注意力计算中，按区域蒙版和权重混合不同提示词的结果，让每段提示词主要影响指定位置。重叠和柔化用于调节区域之间的过渡；它不是把多张成图拼接起来，也不会自动画出漫画分格线。

## 安装

在 Forge 的 **Extensions → Install from URL** 中填入：

```text
https://github.com/linnnn89/forge-regional-prompt
```

安装后重启 Forge 并刷新页面。若已安装原版 Forge Couple，请先禁用原版，避免同时加载两份插件。

本地使用环境为 Forge Neo、Gradio 4.40.0 和 Anima。具体效果与验证范围见下文；其他模型、版本及扩展组合未做完整兼容性验证。

## 使用方法

展开 **Forge Couple**，勾选 **Enable**，选择一种模式：

- **Basic**：按提示词分段等分画面。`Horizontal` 为左右分列，`Vertical` 为上下分行。
- **Advanced**：手动设置矩形区域的位置和权重，每个区域对应一段提示词。
- **Mask**：选择模板并点击“应用模板并创建图层”，然后填写每层的提示词。支持 N 列、N 行、四宫格、比例双区（如 2:1、1:2）和一大两小；N 可输入 2–16。

默认每行是一段提示词。例如 Basic 左右两列、Global Effect 设为 `None`：

```text
2girls, red-haired girl, white dress, garden
2girls, blue-haired girl, black dress, garden
```

**Mask 常用操作：**

- **重叠宽度**：增加相邻蒙版共同影响的范围；**边缘柔化**：让边界渐变。两者均按画面短边的百分比计算，设为 0 可恢复原始硬边。
- 预览中的编号对应图层，混合色表示共同影响，亮紫色表示未覆盖区域。
- 上下移动会一起移动蒙版、提示词和权重；删除图层也会删除对应区域提示词，全局提示词会保留。
- 不规则区域可展开“手绘修正与导入”，用纯白绘制后保存为新图层；修改已有图层需先载入，再覆盖。

**通用设置：**

- **Global Effect**：将首段或末段作为全局提示词，其余段数应与区域数一致。
- **Hi-res 时关闭区域控制**：首轮按区域生成，Hi-res 阶段停止区域约束，使用普通提示词继续细化。
- 生成前确认提示词与图层数量匹配，并等待预览更新完成。效果取决于模型对提示词和构图的理解。

## 已做过的探索

这些观察来自有限的本地生成，不是多模型、多 seed 的效果评测。

| 路线 | 做法 | 实际观察 |
| --- | --- | --- |
| 原注意力 | 分别计算各段 cross-attention，再按蒙版混合输出；保留整图 self-attention | 等分区域能起效；非等比分区的蒙版确实进入计算，但人物占位未可靠跟随 |
| 区域去噪融合 | 各区域分别预测完整画面，按蒙版融合；加入整图预测与逐步退出区域控制 | 能运行，但没有解决占位与互动同时成立的问题 |
| 局部画布预测 | 裁剪区域 latent，使用相同局部视野计算正负向预测，再写回共同画布 | 固定 seed 对照出现明显背景割裂，不推荐作为稳定方案 |
| 联合注意力 | 全局与区域条件参与同一次 cross-attention，在 softmax 前加入连续空间偏置 | 一组对照中牵手和背景连续性较好，但横向占位仍未达到非等比目标 |

### 早期联合注意力对照

使用 JANIMA_V1，1280×1024，25 步，ER SDE / Beta，CFG 5，seed `342146220`，无 LoRA、无 Hi-res。相同提示词描述两位成年女性在海边面对面牵手，分别生成原注意力 2:1、联合注意力 2:1、联合注意力 1:2 三张图。

- 原注意力那张没有实现牵手；联合注意力两张出现了手部接触，但手指细节仍不完美。
- 联合注意力两张背景连续，比例对调后人物相对高矮、服装和姿态发生变化，横向站位仍接近。
- 日志确认区域平均权重从约 66.25% / 33.75% 对调为 33.75% / 66.25%。这证明比例进入计算，**不证明最终构图合格**。
- 联合注意力的三项自动检查已通过，覆盖权重计算、批次与正负向处理、补丁恢复及非法权重；自动检查不能替代实图效果判断。

目前只能认为联合注意力值得保留研究，不能据此宣称普遍优于原版。人体大小、精确占位和复杂互动仍由模型理解决定，插件没有提供可靠保证。

### 后续探索与暂停结论

随后完成 A–H 八张同 seed 探索：自然语言主次、联合注意力开关、空间惩罚 4 / 0、区域身份权重 1 / 0.1，以及 `close-up, cowboy shot` 下的普通 2:1 与三等分互补描述。

- 关闭插件也能产生身份分离和手部接触，不能把牵手归功于插件。
- 取消空间偏置后，裁切和偏背面构图仍存在；减弱区域身份条件后，朝向更接近全局描述，但仍有裁切和手部异常。
- 近景两组都出现更明显的左大右小，三等分没有证明优于普通 2:1。头发、裙摆扩大也不能等同于躯干占位达标。
- 没有任何一组证明“精确非等比占位 + 自然互动”已可靠解决；已暂停继续调参、生图和后端改造。参数、提示词及证据边界记录在 [实验记录](docs/EXPERIMENTS.md)。

## 如何试用实验后端

实验选项位于 **Settings → Forge Couple**，应用设置后仅在 **Anima + Mask** 生效，不改变 Basic、Advanced 或其他模型的路径。

- **联合注意力**：Global Effect 必须选 First Line 或 Last Line。全局段描述完整构图和双方互动，区域段描述各人物特征。区域外惩罚默认 4；0 仅取消空间区分，仍拼接多段条件，**不等于关闭插件**。保留灰度与重叠，不硬切断跨区访问。各段按编码序列长度校正权重，不是按有效描述词数或语义信息量归一化。Global Effect Weight 调整全局段相对权重，不等于实际注意力百分比。
- **区域去噪融合**：计算开销更大。整图协调强度默认 0.25，区域约束在模型噪声时间 0.5 开始渐退、0.85 结束；这不是采样步数比例。整图强度设为 0、两项时间均设为 1，可恢复全程区域融合。
- **局部画布预测**：依赖区域去噪融合，各段描述本区域人物，全局段描述整体关系。“周边上下文”只扩大读取范围，不扩大写入蒙版。暂不支持 ControlNet、局部重绘或参考图；区域去噪也不支持 AND 组合提示词及其他扩展同时修改条件区域。

联合注意力优先于区域去噪融合。**恢复原注意力时，同时关闭这两个开关。** 联合注意力使用 PyTorch SDPA 处理带偏置的 cross-attention，速度和显存可能与 SageAttention 不同，尚未做完整性能对照。

日志 `[JointAttention]` / `[RegionalDenoise]` 及 PNG 的 `forge_couple_backend` 用于确认执行路径，不代表画面效果合格。联合注意力思路参考 [Sen-sou 的 Anima 区域条件节点](https://github.com/Sen-sou/Comfyui-Anima-Regional-Conditioning)，本实现保留连续灰度和有限的区域外惩罚。
